# StarLead / 星引 v0.33

## 中文

- 键盘型主面板升级为新的暗色玻璃布局，重新整理了标题、系统入口、键盘区和底部提示的视觉层级。
- 新增面板顶部“键盘型 / 一字型”分段切换器，点击后立即切换并保存。
- 名称、置顶和设置改为紧凑圆形控制；名称与置顶的启用状态会直接高亮显示。
- 键帽悬停缩放调整为更克制的 1.05 倍，并增加紫色焦点边框和柔和光晕，避免布局跳动。
- 键位名称字号和字重提高，工具提示固定使用白底深色文字，继续避免暗色主题下的字体可读性问题。
- 一字型空白区域的右键菜单新增“切换到键盘型”和“设置”，两种面板之间切换更方便。
- 中英文说明书中的暗色主题截图已更新为新版真实界面。

## English

- Redesigned the keyboard panel with a refined dark-glass layout and clearer hierarchy for the header, system entries, keys, and footer hint.
- Added an in-panel **Keyboard / Linear** segmented switch that applies and saves immediately.
- Replaced text-heavy quick controls with compact circular buttons; active Names and Pin states are highlighted directly.
- Reduced key hover scaling to a restrained 1.05x and added a violet focus border and soft halo without layout shift.
- Increased action-label readability and fixed tooltips to dark text on white in every theme.
- Added **Switch to Keyboard** and **Settings** to the linear panel's blank-area context menu.
- Updated both user manuals with real screenshots of the redesigned dark keyboard and linear panels.
