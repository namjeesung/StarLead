# StarLead / 星引 v0.31

## 中文

- 键盘型与一字型动作面板。
- 支持程序、文件、文件夹和本地笔记本。
- 笔记本入口可像普通动作一样移动、交换、删除和重新绑定。
- 支持中文 / English、浅色 / 深色，以及液态玻璃、海湾蓝、极光、石墨四套风格。
- 背景透明度 `0–100%` 实时预览，`0%` 时隐藏背景、外框和阴影。
- 圆形滑杆支持点击轨道直接跳转。
- 回收站右键支持调用 Windows 原生确认后清空。
- 统一界面与右键菜单字体，改善文字可读性。
- 新增中英文用户手册。

安装包适用于 Windows 11 x64，包含运行所需组件。

## English

- Keyboard and Linear action panels.
- Supports apps, files, folders, and the local notebook.
- The notebook launcher behaves like a normal action: move, swap, remove, or bind it again.
- Chinese / English, Light / Dark, and four interface styles: Liquid Glass, Ocean Blue, Aurora, and Graphite.
- Live `0–100%` background opacity; `0%` removes the background, outer border, and shadow.
- Circular sliders jump directly to the clicked track position.
- Right-click Recycle Bin to empty it through the native Windows confirmation flow.
- Unified UI and context-menu fonts for reliable readability.
- Complete Chinese and English user manuals.

The installer targets Windows 11 x64 and includes the required runtime.
