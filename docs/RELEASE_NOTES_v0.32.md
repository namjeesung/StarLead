# StarLead / 星引 v0.32

## 中文

- 回收站图标现在会根据实际状态显示 Windows 系统空桶或满桶图标。
- 每次呼出面板以及执行清空操作后，都会自动刷新回收站状态。
- 回收站为空时，“清空回收站”菜单会自动禁用，不再弹出错误。
- 回收站有内容时，仍可通过右键菜单调用 Windows 原生确认流程进行清空。

## English

- The Recycle Bin now uses the Windows system empty/full icon that matches its actual state.
- Its state refreshes whenever the panel opens and after an empty operation.
- **Empty Recycle Bin** is disabled when the bin is already empty, preventing the previous error.
- When items are present, the right-click action still uses the native Windows confirmation flow.
