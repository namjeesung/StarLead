## 使用

- 默认按 `Ctrl + Space` 呼出动作面板。
- 呼出快捷键的修饰键可选择“无”，支持反引号 `` ` `` 以及 `- = [ ] \\ ; ' , . /` 等符号键单独呼出。
- 双击空白键位，绑定程序、文件或文件夹。
- 也可以从桌面或资源管理器把程序、文件、文件夹直接拖到键位。
- 单击已绑定键位打开目标；发生拖动时会拦截单击，整理键位不会误启动程序。
- 面板打开后，也可以直接按对应的数字或字母键启动目标。
- 直接拖动两个键位即可交换位置。
- 可把任意键位的图标拖到另一个键位：两边都有绑定时交换，目标为空时直接移动。
- 拖动时源键帽变淡、目标键帽紫色高亮放大；交换完成后两个键帽同时闪亮确认。
- 右键已绑定键位可打开、重新绑定或删除。
- 拖动面板顶部可移动窗口；可以设置为记住位置或每次居中。
- 按 `Esc` 或再次按呼出快捷键关闭。
- 设置中可更换呼出快捷键、切换浅色/深色主题、设置开机启动，以及逐个隐藏键位。
- 可选择显示图标名称，或隐藏名称并显示更大的图标。
- 主面板可以直接切换名称显示和窗口置顶。
- 面板顶部固定提供“我的电脑、下载、回收站”三个紧凑的 Windows 系统图标入口，单击打开且不显示悬停提示；下载入口支持系统目录重定向。
- 设置中可分别开关“我的电脑、下载、回收站”，并可在键盘型和一字型之间实时切换。
- 浅色/深色主题与键盘型/一字型样式在点击后立即保存为默认，不需要再点击保存按钮。
- 界面风格、单选框、复选框、滑杆和按钮采用统一圆角视觉；切换风格时立即预览并保存。
- 笔记本现在与程序、文件和文件夹一样作为普通动作：可以拖动、交换、右键删除，也能在空键位重新绑定；键盘型和一字型互不影响。
- 一字型拥有完全独立的无限图标列表：从桌面或资源管理器拖入即可追加，内部拖动可排序，滚轮横向浏览，悬停平滑放大，单击启动，右键删除。
- 一字型每个图标下方显示顺序数字；前十个图标可用数字键 `1–0` 启动，超过十个仍可滚动并用鼠标启动。
- “显示图标名称”同时控制键盘型和一字型；滚轮浏览时，当前选择的图标会持续高亮放大并自动滚动到可视区域中央。
- 设置中可用 `200–1800 px` 滑块实时调整一字型最大长度，并自动适配屏幕宽度；图标较少时仍按实际数量收紧。
- 一字型可直接拖动左右边缘改变长度；空白处右键可切换自适应或自定义宽度，并用滑块实时调整图标间距。
- 两种面板的背景透明度可在 `0–100%` 之间实时调整，图标本身始终保持不透明；设为 `0%` 时外框和阴影也会完全消失。
- 除键帽和按钮外，按住面板任意空白区域都可以移动窗口。
- 点击面板外部不会自动隐藏，保证可以从桌面或资源管理器稳定拖入图标。
- 使用 `Esc`、再次按呼出快捷键，或启动绑定目标后关闭面板。
- 使用 Windows Shell 高分辨率图标，桌面快捷方式拖入后保持清晰。

## 数据位置

配置仅保存在本机：`%LOCALAPPDATA%\StarLead\data.json`。

## 笔记本小桌面

- 主面板右下角的“笔记本”打开独立可视化小桌面。
- 双击空白区域新建纯文字笔记；双击卡片编辑，内容自动保存。
- 自由排列模式支持拖动并自动吸附横平竖直的网格。
- 自动排列模式按“置顶优先、最近修改优先”整理卡片。
- “一键整理”可随时重新排列全部卡片。
- 卡片右键支持编辑、复制文字、置顶和删除。
- 单击卡片高亮选中，`Ctrl + 单击`可多选。
- 右键可为全部已选卡片设置默认、黄、蓝、绿、粉或紫色。
- 笔记只保存在本机，并跟随星引浅色/深色主题。

## 构建

需要 Windows 11 x64 和 [.NET 8 SDK](https://dotnet.microsoft.com/download/dotnet/8.0)。

```powershell
dotnet build -c Release -p:Platform=x64
```

安装包脚本位于 `installer/StarLead.iss`。

英文说明见 [README.en.md](README.en.md)。
